# Still icon

The final source is `StillIcon.png`. Generated with the built-in image generation tool, then resized into macOS icon sizes by the build script.

Initial prompt: A single macOS app icon for a minimal screenshot app called Still. Pale icy-blue rounded-square porcelain base, two floating snapshot tiles, a cobalt-blue front tile with ivory corner crop marks and a small mint dot. Soft upper-left lighting, subtle dimension, transparent outer margin. No text, camera lens, mountains, or busy detail. Readable at 32 pixels.

Final refinement prompt: Keep the snapshot tiles, cobalt composition, frosted base, scale, and lighting. Remove floating fragments, speckles, halos, and stray shadows outside the rounded-square base. Use a smooth antialiased outer edge and transparent pixels outside the silhouette. Preserve centered composition and margin; no text.
